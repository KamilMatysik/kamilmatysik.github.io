Chess in C

As part of my course in university I had to learn C, so I decided to undertake a project that would help me improve my knowledge of the language. I enjoy playing chess in my free time and felt like this would challenge would be the perfect difficulty for my skill level as I already had minor prior experience in C.

It was difficult to implement some of the logic, especially special edge-cases. I was able to implement everything other than an automatic checkmate when the king has no move as that would take knowing what every piece sees at all times and would be tough to do. The code itself can be optimised, however since this was my first time actually implementing C into a project, I was ok with it not being perfect.

It can be downloaded here and is fully playable inside of a terminal once you properly compile and execute it.

File Organiser

I wanted to do a python project that would actually be of use to me, and would not force me to learn modules that I would never use again, so I decided ot do one with the os and shutil modules.

Unlike the previous projects I had done, I knew that the code for this one would be much shorter so I decided to refrain from using tutorials as they would give me the code and not actually teach me anything, and instead I consulted the official documentation, a practice that I needed to learn for the future.

Overall, this project did not present any major difficulties and can be downloaded here. It is personalised towards the downloads folder as that is where I always struggle to find things. There are a few other customisation preferences that can be changed in the code if needed.
